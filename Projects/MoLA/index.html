Abstract

Aligning 3D human motion with language is challenging because body-part movements and sequential events are entangled in holistic descriptions. MoLA is a unified motion–language pretraining framework that explicitly decomposes and aligns motion and language at structural and chronological levels. Large language models reformulate global descriptions into body-part and event-level concepts, providing fine-grained supervision. A part-mixture learning strategy encourages independent modeling of body-part motion. For temporal alignment, Gumbel-based adaptive consistency learning and a chronological order objective associate events with relevant motion clips without explicit boundary annotations. Directional consistency regularization further connects global motions with their local patterns. Experiments evaluate these representations across motion–text retrieval, action recognition, motion captioning, and text-guided motion generation.

Method

Understand the parts. Preserve the order.

A full-body description is useful, but it can hide which limb moves and when each event happens.

  1. Decompose the description

    An LLM turns a global description into five body-part descriptions and up to four ordered events. Uncertain concepts are masked rather than used as supervision.

  2. Learn structural correspondence

    Part-level alignment and mixed-body motion samples reduce shortcuts from co-occurring limb movements, encouraging more precise local representations.

  3. Learn chronological correspondence

    Adaptive event-to-clip matching and an ordering objective learn where events occur. Global-to-local directional consistency connects the representations.
